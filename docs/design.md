# Reference lock

Primary source: PRD visual style and landscape wireframe. Preserve emerald felt, navy framing, gold trim, ivory cards, display serif titles, and a left scoreboard with an eight-card hand. Secondary references: Refero bundled typography (limited scale, readable tabular numerals) and craft-details (visible focus, semantic buttons, touch controls, safe areas). Existing FantomZone source supplies hub card conventions and same-origin art.

Direct build follows the PRD's concrete source. Menu uses an editorial title opposite an original card illustration, with four mode tiles below. Gold belongs to primary actions, money and trim. Blue and red belong to chips and multipliers. Decorative artwork never competes with the playable cards. No fake online counts or fabricated statistics.

Landscape uses dynamic viewport height and a compact layout at short heights; portrait uses a top scoreboard. Native orientation locking is best effort only, after a user fullscreen gesture. Every gameplay control remains usable without fullscreen.
